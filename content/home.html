About

About MuffinEMU

MuffinEMU (also written Muffin EMU or Muffin-EMU) is a free, open-source Wii U emulator for iPhone and iPad, based on Cemu. This is the official MuffinEMU website; the source code is on GitHub at github.com/kiddreads/MuffinEMU.

The core

Console-class emulation, in your hand.

01

Built on Cemu

MuffinEMU runs a Cemu-based core with its own fixes and a selection of upstream Cemu fixes.

02

Metal-native renderer

Metal by default, with Vulkan (MoltenVK) as an option. On older GPUs such as the A12Z, draws that need geometry shaders are skipped, so some effects and a few graphic packs won't look right.

03

Open source

The full source is on GitHub, and every release lists what changed. See Status for what works today.

Pick the source that matches how you install apps. iPhone and iPad, iOS 15 or later.

source https://kiddreads.github.io/MuffinEMU/apps.json

The recompiler (JIT) needs an external enabler — StikJIT, SideStore, TrollStore or LiveContainer. Without one, MuffinEMU uses the interpreter, which is slower.

Status

Where things stand.

Tested on an iPad Pro (A12Z).

Confirmed

Working
  • Some Wii U games boot from a library imported through Files
  • The Metal renderer, the default, draws on the device
  • The multi-core interpreter is the default CPU mode; the recompiler needs a JIT enabler

Still open

In progress
  • No full playthrough of a retail game has been confirmed yet
  • Audio, physical controllers and game compatibility have not been tested widely
  • Output to a second display has not been tried with a display attached
  • Vulkan on A12Z-class iPads does not find a usable GPU; use Metal, the default
  • GPUs without mesh shader support skip geometry-shader and RECTS draws, so some effects can be missing
Credits & license

Bring your own games and keys. No copyrighted content is distributed here — not games, not system files, not keys.

MuffinEMU is built on Cemu. The optional melo-controls pad is Melo-Controller by stossy11 (GPL-3.0). The Vulkan path uses MoltenVK.

MuffinEMU's own source is MPL-2.0, like Cemu. Because Melo-Controller (GPL-3.0) is linked into every build, a MuffinEMU IPA as a whole is distributed under GPL-3.0, with the repository above as its source.
